# 网易云歌词背景

把网易云音乐当前一句歌词铺在 DSH 工作区上，替代网易云自带的桌面浮窗。

## 前提

- 桌面版网易云音乐正在运行，并且已在 **设置 → 常规 → 系统** 打开 **开启 SMTC**（名称可能显示为“系统媒体控制”）。不开时 Windows 的
  `GlobalSystemMediaTransportControlsSessionManager` 根本不会出现网易云会话，宿主拿不到任何曲目数据。
- 网易云桌面版不上报播放进度；宿主用 SMTC 的标题、歌手、播放状态作锚点，再用宿主时钟推进当前句。
- 本插件是 Windows 专属：宿主用 `powershell.exe` 读取 SMTC，用网易云公开的搜索和 `/lyric` 接口取 LRC。

## 调节颜色与对比度

两种入口，改的是同一份设置：

- 随时按 **Alt + L**，或点关闭按钮/背景关闭，打开快速调色面板。
- 也可以在 Harness 的 **设置 → 歌词背景** 里找到同一个面板。

面板提供：

- **跟随主题**：深色主题使用 DSH token 混出的低饱和品牌红，浅色主题使用墨灰。
- **自定义颜色**：原生取色器、十六进制值、四个快捷色。
- **显示强度**：2%–35%，改动实时作用于歌词图层；有 8% / 14% / 22% / 30% 快捷档。
- **歌词 / 背景对比度**：按当前主题背景、当前颜色和显示强度合成后计算并显示相对亮度比。
- **恢复默认**：回到跟随主题 + 8%。

设置保存在当前浏览器（`localStorage`），刷新页面后保留；只影响歌词图层，不改 Harness 主题或正文颜色。

## 行为

- 界面侧只通过 `/netease-lyrics` 宿主 RPC 读取数据；不会在浏览器里访问系统媒体 API。
- 当前句只在中间会话栏的水平范围内显示，字号为视口宽度的 8%，句子过长时等比缩小。
- 深色主题使用从 DSH 颜色 token 混出的低饱和红；浅色主题使用 DSH 的墨灰色。
- 句子之间 500 ms 交叉淡入淡出；只在图层内部改 opacity，不改变任何布局尺寸。
- 窗口宽度小于 900 px 时整层 `display:none`。
- 图层 `pointer-events:none`，不进入 tab 顺序，不接收焦点。
- 接口不可达、搜不到、LRC 为空时保留上一句并降到 3% 透明度；连续 3 分钟没有播放时整层淡出。
- 播放器没开时宿主不发起网易云请求。
- 切换歌曲后重新取 LRC；LRC 按 songId 缓存在宿主内存。

## 关闭

在 **插件** 页面关闭“网易云歌词背景”或从本 profile 移除 bundle 后，客户端图层、宿主 RPC 和 SMTC 子进程会一起卸载。

## 已知限制

- 网易云不上报 SMTC 进度，拖动进度条后宿主时钟会与客户端进度不一致；换歌或重开客户端可复位。
- DSH 的内容栏本身有不透明表面，因此歌词层是位于内容之上的 8% 水印层（仍低于 `shell.overlay` 的弹层）；它以 `pointer-events:none` 保证不挡交互。
- 没有可用的网易云 SMTC 会话时不会伪造曲目，也不会显示错误文字。
